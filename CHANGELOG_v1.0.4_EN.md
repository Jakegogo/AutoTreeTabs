# Auto Tree Tabs v1.0.4 Release Notes

**Release Date**: May 14, 2026  
**Version**: v1.0.4

## ✨ UI Improvements

### 🌙 Dark Mode Support
- Fixed selected search tags using a light background in dark mode
- Selected and active tags now use shared theme variables for better consistency across light and dark modes

### 🌓 Theme-Aware Icon
- Popup title icon now switches automatically based on the system light/dark theme
- Light mode uses the white-background icon, while dark mode uses the black-background icon for a more consistent UI
